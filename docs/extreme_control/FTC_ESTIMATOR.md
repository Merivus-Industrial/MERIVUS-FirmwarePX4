# FTC 电机效能估计

`motor_health_monitor` 对时间对齐后的 `actuator_motors` 与 IMU 角加速度建立多输出 RLS 模型。名义分配矩阵给出各电机对三个转动轴的方向，健康 Baseline 学习每轴尺度，随后估计每台电机的无量纲效能 `lambda`。`lambda` 同时缩放该电机对应的推力和三个力矩列，是工程近似，不是独立推力或偏航力矩标定。

估计更新需要足够油门、激励、可接受的回归条件数、有限输入、未饱和控制以及足够低的残差。`confidence` 由协方差和残差映射得到，是质量评分，不是校准后的故障概率。`estimate_age` 表示距最近一次更新的时间；`last_valid_timestamp` 记录最近一次通过完整有效性门的时间，两者不可互换。提交 `3b4304e253` 修正了有效性退出后历史认证时间的生命周期。

当前证据边界：

- 理想 Host 模型的 24 个静态真值场景最后窗口最大 MAE 为 `0.000001`，其他电机最大误差为 `0.000003`。
- 4 秒故障/4 秒恢复的间歇场景未通过，目标电机 MAE 为 `0.304411`，其他电机误差最高 `0.319358`。
- 7 次正常 SITL 飞行均未通过最终注入准入。最近 3 次只有约 `5.39%–6.00%` 的飞行窗口为 `valid=true`，不能形成稳定 Baseline。
- 截图中约 `0.02` 的 confidence 与 `valid=false` 符合低激励、较大不确定度和模型残差共同门控的结果，不能通过降低阈值解释为有效模型。

低激励下无法稳定建立真实 SITL Baseline 已登记为 `KNOWN_LIMITATION`。项目收尾不再调整估计器算法；后续若恢复研究，应从物理输入尺度、命令—响应时延、刚体耦合项、Baseline 增益和不确定度覆盖率入手，并以新的 ULog 证据重新准入。
