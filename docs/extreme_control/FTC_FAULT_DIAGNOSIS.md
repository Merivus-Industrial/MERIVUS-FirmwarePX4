# FTC 故障诊断

诊断层消费有效的 `lambda`、不确定度、残差、ESC telemetry 和外部扰动指标，输出每台电机的 health、fault probability、fault type、持续时间以及 degraded/failed mask。退化和失效都需要置信度及持续时间门，模型无效时不得用历史数值宣告当前健康。

物理归因遵循证据边界：全机振动或单一 `lambda` 下降只能支持“推进异常”，不能单独断言桨叶破损、电机机械损伤或某个电调供电故障。ESC 转速、电流和电压证据可用于增强停转或供电类判断，但 SITL 证据不能替代真实台架标定。

4 项分类选择函数测试通过。7 次正常 SITL 飞行的统计窗口内 degraded/failed mask 均为 0；由于估计器准入失败，没有执行真实推进故障阳性注入，因此识别延迟、定位率和物理分类准确率均未验证。
