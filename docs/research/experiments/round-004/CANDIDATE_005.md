# 候选 005：固定风静默阈值的稳态悬停补偿

状态：`DISCOVERY_INCONCLUSIVE`。继承候选 004 的已稳定定点悬停启用条件和补偿图，仅把水平速度误差门控关断阈值从 0.05 m/s 提高到 0.08 m/s；全开阈值保持 0.25 m/s。候选 004 的固定风预筛查记录中，启用后至评分窗口结束的速度误差最高约 0.060 m/s，却出现峰值 0.00216 m/s² 的早期修正，超过[第四轮协议](PROTOCOL.md)的零输出门槛。0.08 m/s 给该观测留有约 0.02 m/s 的余量；这只是发现集上的设计依据，不能保证其他种子同样静默。

```text
q      = ||e_v,xy||₂
g(q)   = clamp((q − 0.08) / 0.17, 0, 1)
raw_xy = 0.15 e_v,xy − 0.15 [L_0.12(r_xy) − L_1.5(r_xy)]
Δa_xy  = sat_0.35(g(q) × raw_xy)
Δa_z   = 0
u      = u_PX4 + Δa
```

更高关断阈值可能损失阵风初期或停风末期的补偿，必须同时检查事件 XY、恢复 XY、Z 和电机指标。候选在发现集通过后才冻结并进入一次性保留集；输出零门槛和阵风收益门槛不因候选表现调整。
