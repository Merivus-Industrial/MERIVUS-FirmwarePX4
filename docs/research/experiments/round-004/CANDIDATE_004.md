# 候选 004：稳态悬停启用的门控瞬态补偿

状态：`SCREENING_REJECTED`。候选 004 沿用候选 003 的速度误差门控、带限残差和水平修正系数，改变控制入口的启用边界。[候选 003 诊断](../round-003/RESULT.md)发现其在起飞收敛和降落阶段施加修正，虽然正常、固定风和固定载荷评分窗口修正为零。候选 004 只有在 Position/Loiter 模式的定点设定稳定、位置及速度连续 2 秒处于[协议](PROTOCOL.md)规定范围后，才进入 `shadow` 或 `active`。设定点移动、离开模式或着地则立即退出；阵风造成的短时位移不使已建立的悬停状态退出。

进入后的水平控制律仍为：

```text
q      = ||e_v,xy||₂
g(q)   = clamp((q − 0.05) / 0.20, 0, 1)
raw_xy = 0.15 e_v,xy − 0.15 [L_0.12(r_xy) − L_1.5(r_xy)]
Δa_xy  = sat_0.35(g(q) × raw_xy)
Δa_z   = 0
u      = u_PX4 + Δa
```

入口未满足时 PX4 原生控制律运行，候选状态重置。假设是：控制器只在已建立的定点悬停下介入突发水平阵风，消除起飞和降落的非目标作用；正常、固定风和载荷工况应记录全程零修正。入口条件可能导致迟滞、错过刚起飞时的扰动，也可能在定位噪声较大时始终无法启用。只有发现集与一次性保留集都通过，才视为当前 iris/Gazebo 场景下有效。
