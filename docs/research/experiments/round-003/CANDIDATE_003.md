状态：`DISCOVERY_REJECTED`。本候选在[第三轮预注册协议](PROTOCOL.md)固定后提出，沿用[候选 002](../round-002/CANDIDATE_002.md)的残差滤波和水平速度反馈，只在输出前增加一个连续门控。两个发现种子已完成，种子 12 触发固定风回退门槛；见[结果记录](RESULT.md)。未运行保留集。

设水平速度误差大小为 `q = ||e_v,xy||₂`，门控权重为 `g(q) = clamp((q − 0.05) / 0.20, 0, 1)`。候选修正为：

```text
raw_xy = 0.15 e_v,xy − 0.15 [L_0.12(r_xy) − L_1.5(r_xy)]
Δa_xy  = sat_0.35(g(q) × raw_xy)
Δa_z   = 0
u      = u_PX4 + Δa
```

阈值来自第二轮原生日志：正常悬停速度误差第 95 百分位约 0.018 m/s，阵风窗口约 1.7 m/s。`q ≤ 0.05 m/s` 时不施加候选补偿，`q ≥ 0.25 m/s` 时保留候选 002 的全部修正；中间连续过渡。假设是避免正常悬停中残差代理噪声对执行器的扰动，同时保留阵风期间的瞬态水平修正。若风扰下速度误差低于门槛，修正会减弱；门控也可能改变闭环相位和恢复过程，这些都必须通过 SITL 对照检验。
