# AFCR 第三轮预注册 SITL 协议

本协议在候选 003 的闭环试验前固定。候选 002 按[第二轮协议](../round-002/PROTOCOL.md)正式淘汰，不因本协议重判。第二轮重复试验显示：即使传给 Gazebo 相同种子，正常悬停厘米级位移仍有运行间波动；以单次 15% 相对差值作硬拒绝会混入该波动。正常基线三次重复的锚点 XY RMSE 约为 0.046–0.055 m，Z RMSE 为 0.094–0.108 m。绝对容差据此设置，并保留原始数值及全部失败试验。

## 试验与门槛

- 场景、阵风强度与时间、15 秒评分窗口、前 2 秒真值锚点和安全硬门沿用第二轮，不根据候选表现修改。奇数种子先跑 `active`、再跑 `off`；偶数种子顺序相反，以降低固定先后顺序的偏差。每轮先执行阵风 `shadow` 的 `AFCR_DA` 限幅、有限值和样本数门控。
- 正常悬停的锚点 XY RMSE 相比同种子基线最多增加 0.015 m，Z 最多增加 0.020 m；平均电机输出平方和最多增加 5%。固定风和固定载荷的锚点 XY/Z RMSE 各最多增加 0.020 m。
- 阵风从第 46 秒至评分窗口结束的 XY RMSE 至少降低 0.080 m；停风后的 XY RMSE 至少降低 0.050 m；阵风事件 Z RMSE 最多增加 0.050 m。所有场景继续要求硬门通过，平均电机输出平方和不得高于基线 5%。改善是绝对位移量，不能仅由原生基线几厘米的小分母放大得到。
- 种子 11、12 为发现集，可用于改候选，但每次都保留失败记录。候选、阈值和评分器冻结后，种子 21、22、23 为一次性保留集；三个种子全通过才标为“SITL 阵风悬停候选通过”，不外推到实机、其他机体或定位源。

本轮候选的门控阈值由[候选 002 结果](../round-002/RESULT.md)中原生 ULog 的速度误差分布决定。正常悬停第 95 百分位约 0.018 m/s，阵风窗口约 1.7 m/s；门控应在两者之间连续过渡，并在正常悬停关断补偿。单凭离线分布无法证明闭环稳定，须通过完整 SITL 对照。
