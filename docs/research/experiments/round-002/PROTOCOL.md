# AFCR 第二轮预注册 SITL 协议

本协议在选择第二轮候选参数前固定。首轮两个“种子”仅改变风向，未设置 Gazebo 随机种子；此外原始真值与 PX4 位置设定点之间的 Z 偏移会影响短窗口 RMSE。修正后的试验器将 `seed` 传给 `gzserver --seed`，但相同种子的进程调度仍可能造成波动。种子 11 的三次原生正常试验，原始 Z RMSE 为 0.098、0.181、0.110 m；以窗口开头真值为锚点后的 Z RMSE 为 0.094、0.108、0.097 m。随机数固定并不等于整套 SITL 按位确定。

## 场景和指标

- `normal`：无外加风；`wind`：起飞前已有的 4 m/s 固定风；`payload`：起飞前固定 1.8 kg 模型；`gust`：原生 Gazebo wind plugin 在仿真第 46–51 秒提供 8 m/s 阵风，之前平均风速为零。奇偶种子改变水平风向。场景 XML 和种子随每次试验保存。
- 评分窗口为悬停阶段约 15 秒。使用窗口前 2 秒的仿真真值位置中位数作为本次试验的固定锚点，计算全窗口 XY/Z 位移 RMSE；阵风额外计算事件开始至窗口结束的 RMSE、峰值，以及停风后的 RMSE。锚点不能落在阵风内。
- 原始真值相对设定点的 XY/Z 峰值继续用于硬门（2 m/1 m），并要求位置漂移峰值、控制分配失败比例和飞行模式通过既有硬门。锚点位移用于比较物理悬停稳定性；原始误差仍保留在结果 JSON，避免掩盖定位和目标跟踪问题。
- 正常悬停的锚点 XY/Z RMSE 单种子不得比基线高 15%，平均电机输出平方和不得高 5%；每个受扰场景的锚点 XY/Z RMSE 不得高 20%。阵风事件 XY 或 Z RMSE 至少一项需比基线降低 10%。这些门槛是候选筛选条件，不是统计显著性或实机安全阈值。

## 顺序与保留集

1. 先用原生 `off` 跑阵风基线，确认 XML、事件时间、ULog 和评分结果符合本协议。
2. 根据首轮日志设计一个候选，在 `shadow` 中检查输出、数值边界和计算路径；再用种子 11、12 做 `off`/`active` 发现集对照。发现集可以用于修改候选，但每次修改都必须保留版本和失败结果。
3. 候选及评价器冻结后，使用此前未参与设计的种子 21、22、23 做保留集对照。三个种子全部通过本协议才标记“值得继续 SITL 验证”。保留集失败后不得在同一保留集上调参并重新宣称独立验证。
4. 即使通过保留集，也须增加不同噪声、阵风幅值、估计器状态和硬件在环验证，才可讨论实机使用。当前工作只运行 SITL。

## 候选设计依据

首轮 `shadow` 日志中，有界残差补偿在正常悬停时出现持续的 XY 平均修正（约 0.04、0.06 m/s²）；首轮 Active 在多个受扰场景的物理位移指标退化。残差代理量是“速度导数减上一周期加速度设定点”，还包含估计噪声、执行器滞后和模型误差，不能当作纯外扰。下一候选应限制慢偏置进入补偿，并用低增益速度反馈维持阻尼；该耦合结构尚未证明优于 PX4 原生速度环。
