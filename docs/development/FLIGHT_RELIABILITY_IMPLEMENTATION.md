# 飞行可靠性实施与验收边界

本页记录当前源码的设计和验证状态。事故证据见项目的 `analysis/20260827/20260827试飞事故分阶段复盘报告.md`。事故固件记录为 `47a595fec735070412f3dc79b0dfc714f96d9c10`；当前产品仓库的上游来源和差异以 Git 历史为准，不能将当前修改称为事故固件的原地补丁。

## 责任边界

## 模式和角色检查矩阵

| 模式 | 人工输入的含义 | 推力来源 | 失联或估计异常时须核对 |
| --- | --- | --- | --- |
| Stabilized | 油门为推力请求，横滚/俯仰为倾角请求 | 人工油门经姿态/角速度控制 | 无自动定高或定位；回中不等于刹停，需核对开关及油门曲线 |
| Position | 摇杆给运动意图 | 位置/速度控制器依据估计计算 | 原始高度、估计 z/vz、目标、推力和模式接管时序 |
| Hold | 自动保持目标 | 位置/速度控制器 | 估计重置、目标坐标系及失联保护入口 |
| RTL | 自动返航目标 | 导航及位置/速度控制器 | 航向、Home、返航开关与保护触发来源、退出接管 |

上述矩阵适用于当前多旋翼主链。FMUv6C 默认使用 EKF2；LPE 是可选消费者，须单独验证才可作为产品配置。所有受支持板型、接收机协议及主从角色切换都必须用实际参数和启动脚本重新确认，不能从板级默认值推断机上已存参数。

## 源码边界

- [GNSS 速度契约](../reference/GNSS_VELOCITY_CONTRACT.md)定义 `vel_ne_valid`、`vel_ned_valid` 和未知精度。固定 GPS 子模块仍在 NMEA 解析器内部使用旧标志；主仓在发布边界纠正公共语义，不修改子模块固定提交。
- 当前 NMEA `sacc=0` 是未知精度，GSF 备用航向仍要求接收机报告有限且正的精度。不能填写假精度或无替代来源时关闭磁检查。实际双天线航向是否发布必须用 `heading` 与 EKF 融合标志确认。
- FMUv6C 真机使用 `px4_fmu-v6c_default`，不编入板内 SIH；主机仿真使用 `px4_sitl_default`。FTC 主动分配与恢复参数默认关闭；上电后仍须核对设备保存值。
- 全高度源失效时 EKF2 原有零垂速紧急回退仍存在。这是单独的故障回退决策，不是 GNSS 提供了零垂速；必须在失效场景验证后才能评价其安全性。

## 软件证据与未闭合项

外部 v2 参考包的固定基线为 `b5354d9d284861f8b8c10b001a6832227b17ccd4` 加补丁。该包报告 ARM/SITL 构建、190 项相关原生回归和 46 项 FTC 主机检查通过；这些证据不自动适用于本仓当前提交。

v2 两次最终通用 SIH 闭环场景总体均未通过预设水平保持门槛：末段真值水平 RMSE 为 1.184 m 和 1.200 m，门槛为 0.8 m。离线证据中，两次末段真实东向平均误差约为 −1.157/−1.173 m；估计减真值东向平均偏差约为 +0.490/+0.496 m，估计相对目标仍约偏 −0.667/−0.677 m。这同时指向估计与跟踪误差，不能仅靠修正坐标映射解释。模拟 GNSS 提供完整三维速度，没有覆盖事故中的 NMEA 缺 Down 链路；没有同条件父提交对照，不能把差值归因于本批代码，更不能直接据此调 7 寸机 PID。

当前仓库的源码在 Windows 工作区修改；本机无 WSL、C++/ARM 工具链，尚未完成当前版本的 ARM/SITL 构建、原生回归、NMEA 原始报文集成、配对闭环对照、台架或实飞。已运行 `git diff --check`、本轮 Markdown 相对链接及 Python 语法检查；使用 v2 数值脚本对当前 `SensorGpsSim.cpp` 的 `round` 表达式检查了 57,602 个坐标与 0.1 m 步进断言，全部通过。该数值检查不加载传感器模块，也不证明真机 GNSS 精度。验证状态保持 `IMPLEMENTED_UNVERIFIED`。构建环境具备后按[测试矩阵](../testing/TEST_MATRIX.md)重建 uORB、运行二维/三维/混合及急停/FTC 回归，并分别记录退出码、日志、工具链、提交与产物 SHA-256。闭环验收须预设门槛并保留所有运行，包括失败。

## 拆桨台架和受控飞行前置条件

1. 确认板型、硬件修订、固件/参数与日志备份；核对 `SYS_HITL`、FTC 开关、电机映射、输出协议和紧急停止动作。
2. 用独立仪表核对电池总压、单节及带载压降，检查线束、连接器、电源模块和 5 V 供电；记录飞控电压、电流与仪表差异。
3. 在良好 GNSS 条件下保存原始报文，拆桨做已知上下移动：上升 NED Down 为负、下降为正；没有 Down 报文时有效位必须为假。
4. 逐一核对模式、返航和急停物理开关到 RC 通道、`manual_control_switches`、`nav_state` 与执行器输出的映射；复核磁环境、实际航向来源和 21–22 Hz 振荡。
5. 仅在供电、估计、控制权和机械问题分别闭合后，组织受控飞行验收。软件编译或通用 SIH 完成起降不等于真机可放飞。
