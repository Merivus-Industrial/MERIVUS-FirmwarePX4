# GNSS 速度维度与精度契约

本契约描述当前源码。实机状态为 `IMPLEMENTED_UNVERIFIED`；当前提交的构建和测试状态见[飞行可靠性实施记录](../development/FLIGHT_RELIABILITY_IMPLEMENTATION.md)。

## uORB 输入

`msg/SensorGps.msg` 同时生成 `sensor_gps` 与 `vehicle_gps_position`。新增 `vel_ne_valid`，原 `vel_ned_valid` 保留三维语义：

| vel_ne_valid | vel_ned_valid | 可用速度 |
| --- | --- | --- |
| false | false | 无有效速度 |
| true | false | North、East；Down 未提供 |
| false 或 true | true | North、East、Down；兼容原三维驱动 |

有效标志不能代替有限值检查。二维消息中的 `vel_d_m_s=0` 只是存储占位，不是零垂直速度观测；禁止不看标志就融合、重置或转发该值。公共消息保留有限占位，缺测 NaN 仅在 EKF 私有样本与维度诊断中使用。

固定版本的 NMEA 解析器属于 GPS 子模块，原速度标志将 RMC/VTG 水平速度误称为完整三维。主仓 GPS 发布层使用副本，在定位有效且速度数值有限时只声明二维有效，并清除三维标志；不改变子模块或解析器的持久状态。没有可用水平速度时不可宣称二维有效。混合输出只有所有正权重贡献者都提供某维度，才声明该维度有效。

`s_variance_m_s` 沿用原接口的 m/s 精度尺度，不因字段名称而再次开平方。零表示未知，不是完美精度；负数、NaN、Inf 是非法值。混合时任一贡献者精度未知，混合精度也为未知；非法精度还会撤销混合速度有效标志。

## EKF2 处理

- 二维 GNSS 只更新、门控、融合或重置水平速度；不得用缺失的 D 做垂直速度一致性或惯导故障判断。
- 垂直辅助来源计数仅在 GNSS 正在使用、D 有效且速度融合配置允许时计入 GNSS。
- 已收到 GNSS 样本但缺失 D 时，其创新、方差、比值输出 NaN；从未收到 GNSS 样本时保留旧接口的零初始化诊断，不代表测量有效。整体速度创新指标只汇总可用轴。日志/分析端不得把实际缺测 NaN 替换为“检查通过的零值”。
- 起飞前垂直创新均缺测时清除该创新低通状态；无穷创新仍判为失败。既有高度和其他起飞检查保留。
- 主 EKF 对零精度保留已有 `EKF2_GPS_V_NOISE` 噪声下限假设，没有把该假设写成接收机提供的精度。
- GSF 只需水平速度，但仍要求有限、正的接收机精度且满足原有精度门。当前 NMEA 的 `sacc=0` **仍不能启用 GSF**。本次不伪造精度，也没有声称完成 GSF 航向恢复。

三维 GNSS 仍进入原三维融合路径。全高度源失败时既有的垂直零速紧急回退未在本次重新设计，它不是 GNSS D 观测。

## 影响范围与兼容限制

当前覆盖 GPS 发布、GPS blending、EKF2、LPE 的 GNSS 速度更新、UAVCAN GNSS 发布、Sagetech 的分维有效性、Open Drone ID、UAVIONIX ADS-B、GPS_RAW_INT、GPS2_RAW、GHST 和 CRSF 输出。LPE 使用无观测的零行处理缺失 Down 维度，该行不参与状态更新或卡方自由度；缺失的垂直创新显示为 NaN。UAVCAN 速度协方差按有效维度转为标准差，非法精度在 EKF 输入处被拒绝；Sagetech 分别声明水平和爬升有效性。GPS_RAW_INT/GPS2_RAW 对无效水平速度及航迹发送协议未知值；GHST/CRSF 在无效速度时不发送相应 GPS 速度帧，地速使用协议规定的 km/h 单位，没有修改线协议。

新增 uORB 字段改变内部生成接口。工程师接手时须一致重新生成消息并完整构建，不能混用新旧生成头文件或模块；离板订阅、ULog 工具和固件外消费者需核对兼容性。旧日志缺少新字段，不能自动认定旧 NMEA 的 `vel_ned_valid=true` 真的提供 D。

**此契约尚未覆盖所有可选消费者。** HomePosition 的未知速度精度门限仍需结合使用方式复核；MAVLink 原始 GPS 消息的 `vel_acc` 字段没有协议规定的未知值，非法或未知精度只可安全编码为零，接收端不能据此判断为完美精度。LPE、UAVCAN GNSS 和各遥测输出的源码处理尚未得到本次目标构建或闭环验证。FMUv6C 默认使用 EKF2、不包含 LPE；其他构建或外设组合须先验证。本修改不构成任意板型/估计器组合的通用验收。
